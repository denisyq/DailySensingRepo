🔴 Edge 158 Web 平台发布说明（11-19 官方）：增量渲染 / WebTransport / Wasm Custom Descriptors V2重点关注已正式发布

来源：Microsoft Learn（官方一手）· 2026-11-19 · 原文链接

Edge 158 平台说明确认三项对 TV 有直接影响的能力：① OfflineAudioContext 增量渲染——音频图分块处理交付，显著降低大音频任务的内存峰值，官方明确「利好内存受限设备」；② WebTransport 新增 reliability / supportsReliableOnly / draining / 并发流提示等属性（对应 W3C 规范），低延迟直播传输层的 Web 侧能力补齐；③ WebAssembly Custom Descriptors V2 与 gamepadrawinputchanged（游戏手柄原始输入）等 Origin Trial 继续。另含 focus-without-user-activation Permissions Policy（iframe 焦点策略收紧）。

影响：「增量渲染降内存峰值」是低 RAM 机型 WebApp 兼容性的正面信号，建议纳入 Tizen Web Engine 能力白名单评估清单（与 048 期 focus-without-user-activation / Web Install API 两项合并评审）；WebTransport reliability 语义需在 LL-HLS/低延迟直播 Web 播放器路线图中占位。
