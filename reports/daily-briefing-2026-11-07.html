🔴 重点关注已发布Fox 完成 220 亿美元收购 Roku，FAST/CTV 出现「超级平台」

来源：Media Play News · The Verge · deadstack · 2026-11-06

Fox 于 11-06 正式完成对 Roku 的 220 亿美元收购交割，将 Roku OS / The Roku Channel 与 Fox One、Fox Nation、Tubi 合流，形成「操作系统 + 内容库 + FAST 广告网络」一体的 CTV 巨头。上期跟踪的「传闻/待交割」状态正式闭合为已交割。Tubi（免费 FAST 库）与 The Roku Channel（ Roku OS 内置入口）合并后，成为全美覆盖规模最大的免费流媒体广告盘子之一。

PM 影响：Roku OS 是北美 TV 出货与激活份额最大的平台之一；交易后其内容分发、广告填充与首页推荐位将整体重新谈判排布。三星 Tizen 上 Tubi / Roku 自有内容的合作条款、广告变现分成对比基准随之变化；需评估 FAST 类 CP 在 Tizen 入口竞价能力增强后，对现有内容合作伙伴排序与广告库存价格的冲击。

🟡 持续跟踪OT 开放注册Gamepad 原始输入事件（gamepadrawinputchanged）OT 开放注册，Web Bluetooth GATT 事件对齐

来源：Microsoft Edge 157 release notes · WPT gamepad/webhid · 2026-11-05

Edge 157 平台说明确认 gamepadrawinputchanged Origin Trial 开放注册——原始输入事件绕过标准映射直接上报，供高精度游戏输入使用；同批 Web Bluetooth 将 GATT 通知/指示改为 EventTarget 事件派发，API 形态向 Web 标准事件模型收敛。

PM 影响：对 TV 云游戏场景：原始输入 OT 意味着未来 TV Web 引擎可支持手柄厂商的私有协议细节（摇杆死区、扳机曲线）通过 Web 暴露，差异化外设体验的上限提高；Web Bluetooth GATT 事件化则影响遥控器/配件在 Web App 内的连接管理写法，Tizen Web App 兼容层需留意 API 形态变化。
